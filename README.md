# All Jammed Up

Single-page site built for **All Jammed Up**, a music festival + podcast based in Asheville, NC — Nativ-Works client project.

Static HTML/CSS/JS, deployed via GitHub Pages. Features an event details section, embedded Google Map, Spotify podcast episode embed, and social links.

The festival this page was built for has since passed and the domain is no longer active, so this repo is kept as a portfolio/demo reference of the build.
